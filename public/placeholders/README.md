# Placeholder textures

`default-pixel-clay.png` is the default texture for newly drawn objects. The UV/Paint canvas and the 3D view both use this image once the project loads it into the document.

To replace it, overwrite that file with a square PNG using the same filename. Use a seamless image for clean repeating surfaces. The application reloads it when the page is refreshed.

`low-poly-terrain-alt.png` is an included alternate placeholder.
